# AgriWatch

AgriWatch is a web-based platform designed to help urban and smallholder farmers detect, report, and resolve crop pest and disease issues by connecting them with verified agricultural experts. The platform enables farmers to submit detailed farm issue reports, including images, and receive expert guidance, while also providing a sustainable revenue model through paid expert consultations powered by M-Pesa integration.

---
## Problem Addressed

Many farmers experience significant crop losses due to pests and diseases but lack fast access to reliable expert advice. AgriWatch bridges this gap by offering a centralized digital system where farmers can report problems early and experts can provide timely, actionable solutions.

---
## User Roles

* **Farmers** – Report crop issues, upload images, track expert responses, and receive notifications.
* **Experts** – Review assigned reports, provide professional recommendations, and manage their availability.

---
## Core Features

* User authentication with role-based access (Farmer / Expert)
* Farm issue reporting with image uploads
* Expert assignment and consultation workflow
* In-app notifications system
* M-Pesa STK Push integration for paid consultations
* Profile management for farmers and experts
* Secure and scalable backend built with Django

---
## Tech Stack

* **Backend:** Python, Django
* **Frontend:** HTML, Bootstrap
* **Database:** SQLite (development)
* **Payments:** Safaricom M-Pesa Daraja API
* **Media Storage:** Cloudinary
* **Deployment (Dev):** Ngrok

---
## Project Goal

AgriWatch aims to improve food security and agricultural sustainability by enabling faster pest and disease detection, reducing crop losses, and creating income opportunities for agricultural experts.
